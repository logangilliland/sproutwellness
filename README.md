# Sprout

BUILD A PERSONAL LIFE OPERATING SYSTEM FOR LOGAN

Build a private personal web application that functions as my personal Life Operating System.

The app should combine:

AI chat assistant

Habit tracker

Daily task manager

Productivity tracker

Personal statistics

Finance tracker

Fitness/activity tracker

Goal management

Project management

Calendar/deadlines

Long-term planning

This is NOT just a to-do list.

The purpose is to help me actually manage my life, track whether I'm improving, adapt when life changes, and give me a clear idea of what I should be doing next.

The app should continue being useful for years, not just for the next week.

The application should behave like a living model of my life, not a static checklist.

AI CHAT

The application must have a persistent AI chat assistant.

This is one of the most important features.

The AI should NOT simply be a chatbot that gives advice.

It should be able to read and modify the actual state of my Life OS.

The chat should function as the control center.

NATURAL-LANGUAGE UPDATES

I should be able to tell the AI what happened during my day.

Example:

"I made $87 doing Uber Eats today."

The AI should record the $87.

Example:

"I worked 4 hours."

Example:

"I moved all my clothes to the new room."

Example:

"I didn't work today but I cleaned my room and exercised."
